# Worked example

A small, filled-in catalog for **Sam**, a fictional independent developer with two work streams:

- **tidepool** — a fictional tide-times mobile app Sam builds and sells
- **bakery-site** — a fictional client website build

Everything here is invented. It shows what the files look like after a few weeks of use and one "catalog this chat" run ([`report.md`](report.md)).

Chat keys `a1b2c3d4` and `e5f6a7b8` stand for two chats; `t13` means turn 13 of that chat.
